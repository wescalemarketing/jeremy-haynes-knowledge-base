Read AGENT_START.md at this site, inspect the package instructions, install the package into a new workspace-local folder, run setup, and answer my questions using reviewed source citations. Preserve all coverage limits.

What happens during installation

  1. The agent downloads and extracts the package, then reads the entry instructions.
  2. The installer verifies the SHA-256 file manifest and copies into the explicitly selected folder.
  3. Setup builds a local search index and checks a source-cited query. No API key or external Python packages are required.
  4. The agent searches reviewed claims or browses video metadata and cites the original sources.

Requires Python 3.9+ and SQLite FTS5. Existing different installations are not overwritten. Skill-enabled harnesses may need a refresh after installation. This does not activate outreach or change unrelated agent settings.
